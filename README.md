# Replicação e melhoria — Fast Genetic Algorithm for Feature Selection

Miniprojeto de IA Avançada (UNICAP) sobre o artigo de Altarabichi et al. (*Expert Systems with Applications* 211, 2023), na base census-income.

* `projeto_original/` — código e dados dos autores ([repositório oficial](https://github.com/Ghaith81/Fast-Genetic-Algorithm-For-Feature-Selection)), com apenas 3 correções de compatibilidade (documentadas).
* `nossa_replica/` — o nosso trabalho: notebook único, a melhoria (`DatasetMod.py`), resultados, figuras e README detalhado. **Comece por `nossa_replica/README.md`.**
