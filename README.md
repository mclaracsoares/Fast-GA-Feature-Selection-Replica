# Replicação e melhoria — Fast Genetic Algorithm for Feature Selection

Miniprojeto de IA Avançada (UNICAP) sobre o artigo de Altarabichi et al. (*Expert Systems with Applications* 211, 2023), na base census-income.

* `nossa_replica/` — o nosso trabalho: notebook único, a melhoria (`DatasetMod.py`), resultados, figuras e README detalhado. **Comece por `nossa_replica/README.md`.**
* O **código e os dados dos autores não estão neste repositório**: estão em <https://github.com/Ghaith81/Fast-Genetic-Algorithm-For-Feature-Selection>. O script `nossa_replica/setup_original.py` baixa essa versão (commit `6ac5a7e`) para `projeto_original/` e aplica as 3 correções de compatibilidade, que não alteram a lógica.

```bash
cd nossa_replica
python setup_original.py     # baixa o código/dados oficiais e aplica as 3 correções
```
